# 会话清道

`@local/dsh-session-reaper` · **0.4.0** · Host + Web 客户端

预览并确认清理已停止的会话。

## 使用

安装本目录，重启 DSH 并刷新网页。在会话的“…”菜单中点击“删除会话”。先预览确认，再永久删除，没有撤回入口或回收站；运行中的会话受保护，需先停止。

支持删除已停止的当前会话，完成后刷新列表并切换到其他会话或新会话。操作失败会显示原因；删除成功但刷新失败时，手动刷新列表检查。

## 兼容边界

当前实现适配 DSH 的 Agent 生命周期及 JSONL 会话目录，只支持匹配 `DSH_HOME/sessions` 的布局。上游内部结构改变、路径校验失败或无法安全释放会话时会拒绝删除。

0.3.1 仅统一显示名称，不包含其他分支或历史本地版本的撤回功能。

## 清理预览与批量确认（0.4.0）

插件页可按项目、最近更新时间和名称筛选，勾选已停止会话后预览名称与数量，再明确确认永久删除。会话菜单的单项删除也先预览确认。批量逐项处理，遇到失败停止并保留剩余项；运行状态会在每项执行前重新检查，Host 仍负责最终保护。没有回收站或撤回功能。
