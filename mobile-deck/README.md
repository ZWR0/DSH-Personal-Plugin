# 掌上行舟

手机与 iPad 上的 DSH 移动工作台。它在 DSH Web UI 里新增一个独立页面，用**真实状态**列出会话，把需要 Owner 处理的事项排在前面，并提供进入原生会话的入口。

任务、模型调用、工具执行和文件操作仍然全部在电脑上运行；移动端只负责展示状态、接收输入和远程接管。插件不新建认证、不保存任何凭据、不修改 Tailscale、代理或防火墙，也不轮询宿主。

- 包名：`@local/dsh-mobile-deck`
- 插件 ID / 主面板 key / 设置页 ID：`mobile-deck`
- 版本：0.4.2
- 宿主配置：profile 目录下 `mobile-deck.json`；手机默认入口另存当前浏览器的本地存储。

## 0.4.2 手机插件标签栏

浏览器测试使用模拟宿主标签结构验证 390 px 下滚动到最后标签及焦点可见性；实际宿主改变标记后需要重新适配。

## 0.4.0 关注、分类提醒与待处理中心

- 会话卡片右上角星标可关注 / 取消关注。在各状态分组内优先显示关注项，不改变待处理优先级；关注的空闲会话不受最近会话条数限制。新增「关注」筛选，设置页可清空关注（包括已不在当前目录里的会话）。最多关注 200 项，仅保存当前浏览器。
- 在「插件 → 掌上行舟 → 提醒规则」分别控制「提问 / 审阅」「授权」「任务结束」，可选仅提醒关注会话。规则只影响提示音与即时读屏播报；动态记录、角标和待处理列表不会因静音被隐藏。规则变更不会补播旧事件；仅关注开启但没有关注项时保持静音。
- 点击「待处理」进入待处理中心。提问显示宿主 questions 中的简短问题，授权显示 toolName / reason，计划审阅单独标记。摘要按纯文本渲染并限制长度，不展示任意工具参数或凭据；缺少摘要时提供进入会话的提示，审批与回答依然在原生卡片内完成。
- 关注与分类规则保存在当前浏览器 `dsh.mobile-deck.alert-rules.v1`，不上传到 Host。损坏数据使用默认值；保存失败显示原因，不伪装保存成功。

已检查当前宿主源码，尚无可复用的 Service Worker 推送注册、订阅管理或 Web Push 发送端。因此此版本未实现离页 / 锁屏推送，也不申请虚假的通知权限。要实现可靠后台提醒，仍需宿主增加服务端事件订阅、Web Push 订阅与发送能力，并补充设备注销、通知隐私和点击跳转的完整流程。

## 0.3.1 声音反馈开关

声音反馈开关、激活状态、试听与 10%–100% 音量调节统一放在「插件 → 掌上行舟」；工作台主界面不显示声音控制区。

- 默认关闭。打开开关或点击「开启并试听」会立即激活音频并播放双音试听；开启后可随时再次试听或静音。
- 状态明确区分「已静音」「等待点击激活」「正在激活」「已激活」，不再把已保存的开启偏好当作音频已经可以播放。

- 新提问、新授权、未查看的任务结束事件按原来的去重规则播放提示音；同一批动态播放一次，不补播历史提醒。
- 静音立即停止已调度音符；暂停音频时显示等待激活。关闭页面和卸载插件时释放音频与事件监听。

如果已显示激活但仍听不到，请检查手机的媒体音量、静音设置及蓝牙输出。浏览器无法检测扬声器是否实际出声；锁屏或浏览器后台冻结后仍不保证提示。

## 0.3.0 任务成果与手机默认入口

### 查看任务成果

点击任一会话卡片的「成果」，在工作台中汇总该会话的交付文件与变更文件。数据仅来自宿主的 `deliverables/presented`、`workspace/changes` 持久事件与认证的 `api/changes.summary`；不解析模型回复来猜测文件，不把空闲当成任务成功。

- 默认显示已加载事件窗口中最近 20 次交付 / 变更记录，按路径去重；显示文件描述及最近一次变更的增删行数。
- 点击「预览」进入该会话的宿主原生文件预览；「变更对比」使用原始事件序号、轮次和文件索引打开宿主审阅页。文件类型、大小、下载和读取权限由宿主处理；不调用电脑桌面的“打开文件”接口。
- 有更早记录时提供「加载更早记录」，先展开当前窗口中的较早批次，再按需请求一页历史。不自动读取整个会话库，也不轮询。
- 变更摘要过期或读取失败时保留交付文件，并标明部分摘要不可用；可重新读取。记录中的文件可能已被后续任务修改或删除，预览会显示宿主实际结果。
- 成果区只在展开时持有一个会话引用。关闭、切换会话或连接代际改变时取消请求、移除订阅并释放引用；不把文件内容存入浏览器持久存储。

### 手机默认打开工作台

在手机打开「插件 → 掌上行舟」，开启「手机默认打开掌上行舟」。以后使用同一浏览器打开普通 DSH 地址，配置和会话目录就绪后会进入工作台。

此选项默认关闭，仅存入当前浏览器的 `localStorage`（键 `dsh.mobile-deck.mobile-home.v1`），不会写入 Host 配置或影响另一设备。清除网站数据、切换浏览器后需要重新设置；存储不可用时显示保存失败。

仅在视口不超过 819 px 且主指针为触屏时生效；宽屏平板不自动跳转。插件停用、配置读取失败、已经进入其他面板、启动期间主动导航、URL 含 hash 或 session/resource/path/panel 参数时保留原入口。每次网页加载最多跳转一次，重连或返回前台不重复跳转。

## 在手机上使用

**仍然扫描「远行之钥」的登录二维码。** 掌上行舟是同一个 DSH 网页内的面板，无需另装手机插件或独立 App。

1. 电脑安装并启用掌上行舟，DSH 保持运行；首次安装按提示重启并刷新网页。
2. 手机与电脑之间的网络须可达；使用 Tailscale 时，两端均需连接到允许互访的网络。
3. 电脑打开「插件 → 远行之钥」，确认固定 Token 与远程地址已设置，显示登录二维码。
4. 手机扫码，在系统浏览器中打开并登录 DSH，然后点击对话输入框下方、书本旁的「掌上行舟」图标。如果扫码工具使用内置浏览器，改在日常浏览器打开并完成登录，认证不会跨浏览器共享。
5. 点击会话进入原生对话，发送消息、回答问题和上传附件；查看状态时切回掌上行舟。
6. 以后收藏远程基础地址即可；认证失效或 Token 轮换后重新扫码。二维码只是登录入口，不会替代网络连接。

电脑休眠、关机或 DSH 停止后无法继续远程操作。手机切到后台后连接可能中断，回到前台会重新同步。此版本没有系统推送，也没有独立 PWA 安装入口。

## 安装与启用

1. 在 DSH 原生插件页安装源码目录下的 `mobile-deck` 文件夹；或使用「行囊宝匣」扫描源码根目录后一键安装。
2. 按安装结果提示重启 DSH 并刷新网页。Host 半部分（配置读写）在重启后生效，客户端页面刷新即可加载。
3. 对话输入框工具行会出现「掌上行舟」图标，点击进入工作台。
4. 在「插件 → 掌上行舟」中启停移动工作台、选择布局、调整「最近会话」条数。

关闭开关会移除输入框入口与主面板；插件页中的设置标签始终保留，以便重新启用。

配置保存在 profile 目录的 `mobile-deck.json`：

```json
{ "version": 1, "enabled": true, "layout": "auto", "idleLimit": 8 }
```

- `enabled`：移动工作台是否启用。
- `layout`：`auto` | `phone` | `pad`。
- `idleLimit`：既不运行也不等待的会话显示条数，范围 1–30。

写入使用临时文件 + rename，文件权限为 0600；读取失败或文件损坏时回落到默认值，不会让页面卡住。

## 远程访问前提

「掌上行舟」不负责连接方式。要让手机或 iPad 打开 DSH，需要先满足其一：

- 已通过「远行之钥」配置固定登录 Token 并在该设备完成登录；
- 桌面端已有的 DSH Web 地址在移动设备网络路径上可达（例如 Tailscale），且浏览器已持有有效认证 Cookie。

插件复用 DSH 现有的登录认证、会话、权限与连接机制：它调用的是宿主自带的 `/api` 认证通道与客户端 Session 服务，不复制、不持久化登录 Token。宿主不支持该通道时，配置读写会失败并在页面上显示原因。

「掌上行舟」不做：自动修改 Tailscale、代理或防火墙；提供公网中转；保证后台常驻连接。

## 功能

### 移动工作台

- 快捷入口：`conversation.input.left`；输入框工作台入口：`main` 插槽中以 `mobile-deck` 为 key 注册的主面板 + `sidebar.panellist` 图标。
- 触屏优先：所有按钮最小高度 44 px，不依赖悬停；行本身是按钮，快捷操作独立成按钮并带 `aria-label`。
- 手机单栏；可用宽度 ≥ 820 px 且高度 ≥ 500 px（iPad 横屏、桌面）时自动切换「列表 + 详情」分栏。设置中可强制「手机单栏」或「平板分栏」用于测试。
- 工具栏：新建会话 / 回到会话 / 刷新。
- 底部留出 `env(safe-area-inset-bottom)`，列表区域可滚动，不产生横向溢出。

### 任务与会话概览

分组顺序固定，需要你处理的在最前：

| 分组 | 判定依据（全部来自宿主真实状态） |
| --- | --- |
| 等待我回答 | `ctx.uiSession.sessionStatus` 中该会话存在 `pendingInteraction` |
| 正在运行 | 列表行 `running === true`，或状态快照 `running === true` |
| 最近会话 | 以上都不是；超出 `idleLimit` 的会话不显示 |

每行显示会话标题（`displayTitle`）、状态胶囊、工作目录名与相对更新时间；手机单栏点击直接进入该会话；平板分栏点击先选择详情，再点击「打开」进入。

刻意避免的数据解释：

- 「最近会话」明确写为“既没有运行任务，也没有等待你的提问；这不代表它们已经完成”。没有运行任务的历史会话**不会**被标记为已完成。
- 不使用模型回复文本推断完成或失败。
- 子代理行（`origin === 'subagent'`）与空白会话不进入概览，避免噪音。
- 「已结束（未查看）」只在宿主 `completionUnread` 为真时显示。

### 远程接管

工作台只做两件事，其余交给宿主原生界面：

- **进入会话**：`ctx.uiWorkspace.openSession(id)` + 切换到原生会话面板。流式回复、工具执行详情、提问卡片、附件与拍照上传、运行中补充指令都在原生会话页完成，本页不复刻这些控件（也因此不会出现「看起来能用、实际不支持」的替代操作）。
- **停止当前任务**：通过会话的 `cancel()` 请求 Host 取消，状态机为
  `请求停止中… → 已请求停止，等待确认 → 已停止`。
  最后一次状态以刷新后的宿主行 `running === false` 为准，不根据本地推测写「已停止」。请求进行中按钮禁用，连点不会发出第二条停止指令。宿主不支持在视图外借用会话时，显示明确的失败原因而不是静默忽略。

### 连接与状态新鲜度

连接胶囊区分：已连接 / 正在重连 / 连接不可用 / 等待连接，并显示最近一次成功同步的时间。

- 数据来源是宿主的连接生命周期（`connection.state`），不是页面能否打开。手机能打开页面不等于任务仍在运行。
- 断线时保留已加载内容，并在顶部提示「状态可能已过期」，提供「重新连接」。
- 重新同步时机：`connection/reset`（新的连接代际）、窗口重新可见、`focus`、`online`、`pageshow`，以及手动刷新。**没有轮询定时器**；同一类唤醒事件 15 秒内只触发一次，避免移动端耗电。
- 不自动重发结果不确定的指令：本插件不代发消息，因此不存在重复消息风险；会话内的重发仍由宿主处理。

### 草稿

回复与草稿都发生在原生会话页，沿用宿主自己的按会话草稿机制，本插件不另建第二套草稿存储，也不缓存附件或聊天历史。

### 设置

- 启用 / 停用移动工作台。
- 布局：自动 / 手机单栏 / 平板分栏。
- 最近会话条数。
- 连接状态与最近同步时间，以及「远程地址与 Token 由远行之钥管理」的说明。

保存走宿主认证通道；失败时显示可读原因，不会把未保存的值当成已保存。

## 兼容与边界

### 依赖的宿主接口

会话状态与操作使用 DSH 公开的客户端服务和插槽，不从页面文本推断状态。窄屏插件标签栏另通过公开 DOM 标记适配滚动与焦点：

| 用途 | 接口 |
| --- | --- |
| 会话列表与运行状态 | `ctx.sessions.list`（`ObservableSnapshot<SessionListState>`） |
| 运行 / 等待 / 未查看 | `ctx.uiSession.sessionStatus`（`SessionStatusSnapshot`） |
| 刷新 | `ctx.sessions.refresh()` |
| 停止 | `ctx.sessions.binding(id)?.session.cancel()`（无绑定时 `ctx.sessions.retain` 借用） |
| 打开 / 新建会话 | `ctx.uiWorkspace.openSession` / `startSession` |
| 切到会话面板 | `ctx.layout.selectPanel('conversation')` |
| 连接状态与重连 | `ctx.connection.state` / `reconnect()` / `connection/reset` |
| 页面与入口 | `main`（keyed，key = `mobile-deck`）、`plugins.tab` |
| 配置持久化 | Host 侧 `ctx.connection.fetch.register('/api/mobile-deck/settings')`（认证由 Connection 中间件负责） |

已验证基线：本仓库文档记录的 DSH `ce7073d51254c26cd63b22a60835b8f948deb447`（与「远行之钥」补丁基线一致）。在该基线上 `main` 是 keyed 插槽（已占用 key：`plugins`、`conversation`、`schedules`），`sidebar.panellist` 是列表插槽，`plugins.tab` 供插件注册整页。

向上兼容约定：若某个基线缺少 `sessionStatus` 或 `cancel`，页面会降级或记录 `console.warn` 而不是抛错；`main` 面板注册不依赖任何 owner props（这类变更只影响详情分栏的内容，不影响导航）。

### 与现有插件的关系

- **远行之钥**：继续负责固定 Token、远程地址和扫码登录；本插件不读不写其配置、不触碰 Token。
- **暗金主题 等主题插件**：工作台样式限定在 `mdk-` 类名下；窄屏标签栏样式另外限定于宿主的 `data-plugin-header-part="tabs"` 标记，卸载时移除；颜色使用 `--dsw-alias-*` 主题令牌并带兜底值，因此浅色、深色与暗金主题下都跟随宿主配色。
- **知忆书阁**：输入框工具行的相邻入口，各自维护角标与功能。
- **选项领航 / 引文速递 / 会话清道**：会话清道的删除入口仍在会话菜单，本页不提供删除。

### 不包含的能力（第一版）

Windows 桌面截图与鼠标键盘远控、任意命令执行接口、AI 生成小应用的平台、新认证服务或公网中转、原生手机 App、后台常驻连接承诺，均不在本版本内。

PWA 安装、系统推送与系统分享入口属于后续扩展。宿主当前没有提供插件可注册的 PWA manifest、推送订阅或分享目标接口，因此本版本不展示这些入口；需要时优先在宿主侧增加公开接口，而不是用 DOM 注入模拟。

### 桌面端

桌面端可以打开同一页面预览（宽屏下就是分栏布局），但默认不改变桌面工作流：它只是一个额外的面板入口，不替换会话视图、不注入全局样式、不拦截快捷键。

## 已知限制

- 详情分栏显示的是会话元数据与接管说明，不是原生对话的镜像；真正的对话内容在原生会话页。
- 等待状态来自宿主的 `pendingInteraction`；`approval` 显示授权，`question` 显示回答（可能含计划审阅），其他类型显示需要处理；具体内容与决策在原生页完成。
- 「已停止」以宿主列表行的 `running` 为准；若该行尚未回到列表（例如会话刚被归档），状态停在「已请求停止，等待确认」。
- 没有在真机（iOS Safari / Android Chrome）上做过验证，见下方验证说明。
- 自动分栏要求宽度至少 820 px 且高度至少 500 px；分屏 iPad 与横屏手机的边界属于自动判断，设置页可手动覆盖。

## 验证

仓库内的脚本覆盖插件自身逻辑，均使用临时数据，不接触真实会话或凭据：

```powershell
node tools/mobile-deck-host-test.mjs
node tools/mobile-deck-client-test.mjs
node tools/mobile-deck-startup-test.mjs
```

- `mobile-deck-host-test.mjs`：默认值、校验与钳位、原子写入与 0600 权限、部分保存、非法输入拒绝、RPC 信封校验、损坏记录回落、路由卸载。使用 `mkdtemp` 创建的临时 profile 目录。
- `mobile-deck-startup-test.mjs`：手机选项、桌面 / 停用 / 深链接 / 主动导航保护、会话目录等待、存储不可用及重连不重复跳转。
- `mobile-deck-client-test.mjs`：成果去重、真实记录来源、部分摘要失败、预览地址编码与变更索引、按需加载、关闭时取消请求与释放引用，以及设备设置持久化；在 jsdom 中加载真实 `client.js`，用桩对象提供宿主服务，验证分组顺序与过滤、子代理/空白会话排除、空闲条数上限、打开与新建会话的导航、停止的“请求中 → 已停止”与防连点、断线提示与重连按钮、布局与启停切换（含停用后入口移除、重新启用恢复）、以及 teardown 后焦点事件不再触发同步。

`mobile-deck-visual-test.mjs` 在真实 Edge 中使用模拟会话检查浅色 / 深色、390 / 1280 px、双入口触控尺寸及减少动态效果设置。

未覆盖：真实 Host 往返、真机触摸与安全区、锁屏音频、成果事件和原生文件面板的真实 Host 完整集成、与暗金主题的实际叠加效果。这些需要在实际 DSH 页面里验证，本仓库当前不自动安装到正在运行的 profile。

## 本轮结果摘要（0.5.0）

成果面板顶部展示当前已加载轮次的结束原因、交付文件数量和最后回答摘录。区分正常结束、失败与停止；没有结束记录时明确提示，回答文字不作为文件或检查通过的证据。点击会话的「成果」查看，较早记录仍按需加载。

## 跨会话待办中心（0.6.0）

点击工作台「待处理」，按「全部待办／待回答／待授权／失败任务」查看当前事项。问题与计划审阅归入待回答，授权单独分类，打开对应会话后使用原生卡片处理；宿主清除待处理状态后自动移出。分类计数不受提示音或关注规则影响，搜索仍匹配会话标题和工作目录。

失败任务只认当前已加载最近轮次中明确的 `turn/end.reason.kind: error`，不把停止、中断、正常结束或未查看等同于失败。打开中心时顺序借用并释放已停止会话的读取引用；相关会话更新、连接重建及主动重新核对时再次读取，不做后台轮询。读取不可用会提示数量，已知信息可能暂时过期，不把读取失败当作任务失败。

失败项可「进入处理」或「标记已查看」。已查看标记仅在当前页面内保留，关闭再打开中心仍有效，刷新页面后重新核对；新失败记录不沿用旧标记。任务重新运行时隐藏旧失败，核对到后续正常结束时自动移除。分类及已查看状态不修改宿主任务、授权或回答，也不会自动重试任务。

更新客户端源码后刷新网页生效。定向测试覆盖分类、处理后移除、新失败重现、正常结束清除、读取引用释放和延迟读取取消；浏览器检查覆盖明暗主题与 390/1280 px。

## 手机布局优化（0.6.1）

工作台移除声音状态、开关与试听区，相关设置仅在插件页操作，已有声音偏好继续生效。手机搜索独占一行，主操作三列排列，五个状态筛选按三项加两项换行，计数保持可见，点击区至少 44 px。会话标题为 16 px，说明和操作文字为 13 px；长标题、状态与元数据自然换行。运行中卡片的四个操作按两列排列，避免窄屏挤压。

手机头部随页面滚动，减少持续占用内容高度；声音设置改为单列宽松排版。浏览器检查覆盖明暗主题和 390、430、820、1280 px，验证筛选点击区无重叠，主界面无声音控件，设置页仍可启停及试听。尚未替代手机真机验证。客户端更新后刷新网页即可生效。

## 固定高度页面滚动与文件入口修复（0.6.2）

工作台作为宿主 main 面板中的独立滚动区域，使用受父容器约束的高度和纵向触摸滚动；工具栏、成果区及会话列表在同一个滚动区域内，不再依赖被宿主禁止的页面滚动。较长列表可滚到最后一张卡片，展开成果后仍可继续上下查看。

客户端显式声明 sidebarRight 服务依赖，通过原生文件面板打开文件或交付预览，不再尝试访问未声明的服务。成果面板顶部也提供「文件」入口，即使没有交付登记，也可以进入对应会话的工作区浏览。已有文件读取权限、支持格式与错误报告由宿主负责。

回归使用固定高度且外层 overflow:hidden 的页面，而非无限高度独立页面，验证工作台内部滚动、最后一张卡片可达，以及 390 px 下实际 Chromium 触摸滑动。服务依赖测试拒绝未声明的上下文访问；文件和交付预览导航测试检查目标会话及原生资源地址。浏览器检查仍非手机真机及真实 Host 文件读取的完整端到端验证。更新客户端后刷新网页生效。

## 滚动检查与手机操作优化（0.6.3）

工作台、待办、动态和成果共享纵向滚动；详情栏不再创建额外滚动区域，底部保留安全区空间。插件设置页由宿主插件页的滚动容器承载，展开说明后仍可到达末尾。成果列表顶部和底部均可收起，收起后将焦点与可见位置带回发起操作的会话卡片；重复点击同一会话的成果也会重新定位到成果区。低高度横屏下自动布局保持单栏，显式平板分栏选项仍保留。

浏览器固定高度检查覆盖 24 个额外任务、长待办和动态、32 个交付文件、全部展开的设置说明，以及 390×360 与 844×390 的矮屏和横屏。逐项验证最后一项及底部操作可达、收起后返回原卡片、重复打开定位、强制分栏详情可达、页面不产生横向溢出。现有 390 px 触摸滑动与插件标签横向滚动检查继续保留。文件预览内部由宿主原生预览器负责，本轮未做真实 Host 文件读取与 iOS／Android 真机滚动验收。
