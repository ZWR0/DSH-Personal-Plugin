# 引文速递

`@local/dsh-quote-relay` · **0.2.1** · Web 客户端

将助手回复中划选的文字插入输入框引用卡片，便于针对原文继续提问。

## 使用

安装本目录并按原生插件页提示刷新或重启。在同一条助手正文中划选文本，点击输入框工具行的引用按钮。优先使用原生引用卡片并保留草稿；旧接口环境回退为 Markdown 引用。

支持单字选区。超过 8000 个 Unicode 字符时要求缩小范围，不截断原文；思考区、编辑区、跨回复及非正文选区不处理。

0.2.1 统一显示名称，移除功能后缀，引用行为保持不变。

## 验证

从仓库根目录运行 `node tools/quote-relay-test.mjs`。依赖与环境要求见[仓库说明](../README.md#验证)。
