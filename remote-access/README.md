# 远行之钥

`@local/dsh-remote-access` · **0.8.0**

在 DSH 插件页选择一种手机连接方式。两种连接共用一个网关，切换前先停止当前连接。

- **Tailscale 跨网**。电脑和手机加入同一 tailnet。点击「开启连接」，插件自动获取 DNS 名称，通过私有 Serve HTTPS 8443 转发到当前 DSH 宿主。依赖 MagicDNS 和 HTTPS。Windows 拒绝配置 Serve 时，以管理员身份打开 DSH。
- **局域网**。选择本机 IPv4 地址，点击「开启连接」。手机和电脑要在同一个网络。手机需要信任网关的自签名证书，Windows 可能提示允许专用网络访问。

连接开启后点击「生成配对码」，在两分钟内扫码，然后在电脑端确认。停止连接或退出 DSH 会关闭网关并断开手机。

源码采用 `link:` 安装时，在插件目录安装依赖后重启 DSH。日常使用通过插件页完成。
