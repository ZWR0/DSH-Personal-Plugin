# 选项领航

`@local/dsh-choice-pilot` · **0.5.0** · 原生选择卡片、限时自动继续与主题适配

关键信息澄清和需要用户决定的后续方向使用原生 `ask_user_question` 卡片，用户直接点击选择，无需复制文本或回复序号。可同时执行的建议使用多选，互斥方案使用单选；可补充自由输入，选好后提交，agent 收到答案后继续执行。推荐预选不等于提交，跳过不等于授权。

## 限时自动继续

普通偏好、可逆方案和信息补充问题由模型在 `header` 开头标记 `[自动继续]`，问题正文说明超时规则。Host 对这类 `ask_user_question` 调用默认等待 120 秒；届时取消原生等待，等待工具清理完成，再返回带有「选项领航自动处理，非用户回答」说明的结果。无需保持浏览器在前台。模型未添加标记的问题继续沿用原生等待，插件不会根据问题文字猜测授权。

- 单选只采用唯一的 `（推荐）` 或 `(Recommended)` 选项；多选采用全部明确推荐项。
- 没有明确推荐、单选有多个推荐或要求自由输入时，记录为未提供信息并跳过，不编造路径、文件或其他内容。
- 缺失信息决定正确性或执行条件时，跳过依赖它的部分，继续独立工作；模型在最终回复中汇总自动选择、跳过内容及影响。
- 授权、删除、付款、对外发送、发布、计划审批以及用户要求等待的问题不得标记自动继续；带原生审批意图的问题也不会自动处理。混合批次应拆开。
- 用户在期限内提交的答案优先；取消、停止、卸载及交互故障不视为超时同意。原生 timed 工具先返回 `pending` 时，其等待到期同样触发自动处理；更短的显式工具等待时间优先。已处理问题不重复追问，用户后续修正优先。

可在 profile 的 `choice-pilot` 行设置等待秒数：

```yaml
- id: choice-pilot
  name: '@local/dsh-choice-pilot'
  config:
    timeoutSeconds: 120
```

`timeoutSeconds` 接受 1–2147483 的整数，`-1` 关闭自动处理。它限制整批问题的等待，不为每题重新计时。超时规则在工具调用进入时生效；更新插件不会追溯接管旧进程里已经等待的问题。重启前先停止旧任务，重启后重新继续任务。

## 使用与更新

安装并启用本目录。更新后重启原 DSH 进程，再刷新网页，以同时加载 Host 指引和客户端样式。没有新增工具、设置页或独立弹窗。

卡片沿用当前主题色：选中行显示强调边框、柔和底色与侧边标记，支持键盘焦点、44 px 选项点击高度与 160 ms 状态过渡；减少动态效果设置下关闭过渡。样式只作用于带原生问题标记的选项，停用客户端插件时移除。

## 提问规则

- 先查证已有上下文，低影响且可逆的实现细节自行判断，不额外索取批准。
- 主动给出多个后续行动并邀请用户选择时，调用卡片，不以普通列表加「告诉我方向」结束。
- 可组合的行动使用 `multi_select: true`，例如同时追踪公告和整理笔记；互斥模式保留单选。
- 所选项和补充文字一起作为答案；等待、取消、跳过均不视为同意。

## 能力边界

原生宿主已提供多选与提交逻辑，本插件引导模型正确使用它，并适配其选项样式。Host 使用 `tools/execute` 扩展点限制已标记问题的等待，取消和清理由原生提问工具负责；不是浏览器模拟点击，也不注册第二个提问工具。它依赖部署实际提供的 `ask_user_question` 及模型遵循标记和最终说明指引，不能保证每次模型回复都会调用工具。不会把已有聊天中的普通列表自动改成按钮。自动处理说明写入正常工具结果，可在会话记录和选择回顾中查看，不表示用户亲自提交。工具不可用时模型应明确说明并使用文本提问。

## 验证

`node --check choice-pilot/index.js`、`node --check choice-pilot/client.js` 和 `node tools/choice-pilot-test.mjs` 检查插件加载、指引注册、样式安装及卸载。`node tools/choice-pilot-visual-test.mjs` 使用原生 DOM 标记的样式预览检查明暗主题、390/1280 px、选中区分、触控高度与减少动效；它不是完整会话截图。宿主原生问题组件测试覆盖多选与提交；真实模型是否遵循指引需在启用工具的会话中验证。

`node tools/choice-pilot-timeout-test.mjs` 使用虚拟计时验证推荐项、自由输入、超时、真实回答、审批排除、取消、故障与卸载，并通过原生提问工具及工具执行管线检查自动处理结果的输出。测试不调用模型，不代表已经验证模型会正确标记每个问题或生成最终汇总。

## 选择结果回顾（0.4.0）

输入框上方提供默认折叠的「选择回顾」，读取当前已加载聊天中的最近五组已提交问题与答案，展示多选和补充要求，可定位原问题与回答。没有记录时不显示，不将草稿、预选或跳过解释为授权。

## 视觉优化（0.4.1）

原生选项采用宽松留白、圆角行和柔和主题色选中反馈，键盘焦点单独显示轮廓。选择回顾使用折叠面板，已选项以标签展示，补充文字单独换行；保留多选、提交、原记录定位及减少动效支持。更新客户端后刷新网页生效。
