# 选项领航

`@local/dsh-choice-pilot` · **0.9.0** · 任务完成后的可点击后续建议

选项领航提供 `suggest_followups`、下一步建议及可选的超时推荐策略。任务中的澄清、补充信息、单选、多选、自由输入、等待、取消和迟到回答均由官方 `@deepseek-ai/dsh-tool-ask-user` 与原生界面负责。本插件不注册提问工具、不包装其计时与调用、不生成用户答案、不追加自动重问，也不覆盖原生问题卡片样式或重复展示选择回顾。

## 超时采用推荐方案（可选）

在当前 profile 的选项领航插件行开启，默认关闭：

```yaml
- id: choice-pilot
  name: '@local/dsh-choice-pilot'
  config:
    useRecommendedOnTimeout: true
```

同时在当前 Agent 预设的官方 `tool-ask-user` 行启用 `mode: timed`，用官方 `timeout` 设置等待时间。没有官方限时模式就不会触发默认策略；旧 `timeoutSeconds` 不参与计时。

开启后，提示词要求模型仅为普通偏好、可逆方案使用 `[可逆偏好]` 标题标记，明确推荐项并告诉用户超时行为。官方工具返回 pending 后，插件只追加来源为 `choice-pilot-defaults` 的正常会话上下文，记录原 callId 与默认方案，工具结果及 pending 状态保持原样。单选必须有唯一推荐；多选采用明确推荐项。自由输入、没有推荐或含糊的单选不生成默认方案。

审批、权限变更、删除、发布、付款、对外发送与必须取得答案的问题不得标记，使用官方 `timeout: -1` 等待真实回答。实现还排除显式审批意图和常见高影响操作词，但不能保证识别所有自然语言含义。标记不是授权，模型仍须遵循原有权限规则。

真实答案、取消、工具错误及其他插件阻止或替换结果时不追加默认策略；不修改信号、不自建计时、不额外启动模型轮次。迟到答案仍通过官方通道到达，并优先于默认策略修正尚未执行的工作；不会自动撤销已经完成的操作。最终回复应说明采用了哪些默认方案，而不是声称用户已选择。

## 后续建议

当前任务结束后，模型可调用 `suggest_followups` 提供 1–4 个按钮，每项携带完整请求。工具结束当前轮，不等待或自动选择。输入框为空且无附件时，用户点击通过原生发送接口提交；已有草稿或附件时仅追加，保留原文与选区，检查后发送。点击、插入与保存失败均保留现有输入，不自动重试。

界面只读取成功工具结果，支持原生和 PTC 内嵌调用。新用户消息出现后隐藏旧建议，切换会话不带入旧建议。当前任务必须解决的提问、审批和记忆写入批准不能用下一步建议代替。模型未调用建议工具时不显示按钮。

## 0.8.0 升级

1. 更新本目录，停止并重启原 DSH 服务，再刷新网页，卸载旧进程中的提问包装器和自动修正监听器。
2. 删除 `choice-pilot.config.timeoutSeconds`。旧值暂时接受但只记录停用警告，不设置或限制官方等待时间。
3. 保持当前预设中的官方 `tool-ask-user` 启用。默认阻塞模式不变；如果需要限时等待，在官方插件行设置 `mode: timed` 和 `timeout`，不要配置在选项领航上。

```yaml
# 当前 Agent 预设 config.plugins 内的官方插件行
- id: tool-ask-user
  name: '@deepseek-ai/dsh-tool-ask-user'
  config:
    mode: timed
    timeout: 120
```

官方限时等待返回 `pending` 后仍允许回答；它不是跳过或授权，也不会采用推荐项冒充用户答案。每次调用的等待参数、必须等待时的 `-1`、取消与错误均遵循官方实际 schema 和实现。默认预设不因安装或更新选项领航而被修改。

官方说明见 DSH 源码的 `packages/interaction/tool-ask-user/README.md`。官方聊天已配对显示问题与答案；查看历史请使用原生聊天记录。

## 验证

- `node tools/choice-pilot-test.mjs`：建议工具与单一界面注册、草稿保护、点击发送、失败提示、会话隔离和卸载。
- `node tools/choice-pilot-timeout-test.mjs`：脚本保留旧名称，现验证官方阻塞和限时模式在选项领航启用及卸载前后保持相同 schema、答案、pending、超时参数、取消和错误，不再测试插件自定义超时。
- `node tools/choice-pilot-visual-test.mjs`：建议组件的明暗主题、390/1280 px、触控高度、减少动效，以及原生问题样式未被覆盖。

兼容脚本还覆盖启用默认策略后的 pending 保留、真实回答优先、单选与多选、审批排除、取消、下游策略阻止和卸载。

这些测试不调用模型；它们验证工具与界面兼容，不保证模型每次都会选择调用官方提问工具。
