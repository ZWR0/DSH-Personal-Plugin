# 选项领航

`@local/dsh-choice-pilot` · **0.2.1** · Host 提示词插件

引导模型在关键信息缺失或需要用户取舍时，使用 DSH 原生提问工具和问题卡片。

## 使用

在原生插件页安装并启用本目录，重启 DSH。插件自动注册提问指引，无额外设置页，也不增加重复工具或弹窗。

模型应先查证已有上下文，对可逆且低影响的实现细节自行判断；关键答案到达前不执行依赖部分。问题优先简洁、选项清楚，必要时使用自由输入。

## 能力边界

依赖部署实际提供的 `ask_user_question` 和原生问题卡片，也依赖模型遵循提示词。插件不会自动赋予部署缺少的工具，不能保证发现全部需求歧义。无交互通道时，指引模型使用普通文本说明并提问。

0.2.1 统一显示名称，移除功能后缀，现有提问策略保持不变。

## 验证与更新

语法检查：`node --check choice-pilot/index.js`。实际效果需在提供原生提问工具的 DSH 环境中验证。Host 提示词修改后需重启原 DSH 进程，再刷新网页。
