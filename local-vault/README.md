# 行囊宝匣

`@local/dsh-local-vault` · **0.8.0** · Host + Web 客户端

扫描 DSH 所在设备的插件目录，批量安装、卸载和迁移本地插件。

## 安装与使用

1. 在原生插件页安装本目录，重启 DSH 并刷新网页。
2. 打开「插件 → 行囊宝匣 → 目录安装」，选择插件总目录，自动保存并扫描。
3. 检查候选项，选中待安装或待迁移项，点击“一键安装选中项”。

支持手动输入 Host 设备上的绝对路径。扫描根目录及下两级，不进入隐藏目录、目录链接和 `node_modules`。有效安装会跳过，同名冲突显示原因。

## 批量管理

已安装列表支持搜索和多选。“选择可卸载项 / 清空选择”使用同一个按钮：无选择时选中当前可见的可卸载项，有选择时清空。没有可卸载项或批量处理期间禁用按钮。

点击“卸载选中”后需再次确认；官方、不可移除项及行囊宝匣自身不会进入批量卸载队列。安装和卸载显示进度、当前插件和逐项结果，失败卸载项保留选择以便重试。离开页面后停止启动后续任务，已开始的操作继续执行。

## 目录迁移与配置

移动源码目录后，选择新总目录并扫描。只有旧本地来源不存在、包名一致且可移除的插件才标为待迁移；迁移保留启停状态，不删除磁盘文件。有效来源和官方插件不迁移，也不自动批准安装脚本。

配置保存在 profile 的 `local-vault.json`，迁移恢复状态保存在 `local-vault-recovery.json`。行囊宝匣无法启动时，先在原生插件页移除其旧记录并安装新目录，再重启和处理其他插件。

## 更新与生效信息（0.6.0）

目录扫描分别显示源码版本与管理器登记版本，并标出版本差异。安装结果保留宿主的重启要求；已应用时提示刷新网页加载客户端。宿主未提供真实运行版本，因此界面明确标注未提供，不将登记版本当作运行版本。

## 安装前兼容检查

目录扫描会检查本套件已知插件所需的 Host 方法，缺失项显示在扫描警告中。安装前重新检查，不兼容时返回 `local-vault/incompatible-host`，不执行迁移卸载或安装；同一批次其他插件沿用逐项处理逻辑。更新宿主后，须重启原 profile，再重新扫描。检查不调用认证方法或读取 Token，也不保证客户端插槽、存储布局与所有上游行为兼容。直接从原生插件页安装不经过此检查。

新设备环境检查与统一回归命令见[套件说明](../README.md#新设备安装前检查)。
