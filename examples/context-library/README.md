# 通用书库模板

此目录只包含通用示例，没有真实个人资料。推荐在插件中使用“我的资料（Owner）”或“添加长期记忆”直接填写；也可以先编辑这些文件，再使用“导入 Markdown”。导入会重新生成元数据和启停状态，请以导入预览为准。

如果通过高级设置将此目录选为整份书库，身份默认启用，Owner 与记忆示例默认停用，填写后再启用。切换书库不会合并旧书库。

- `identity.md`：Agent 的定位与沟通习惯。
- `long_term/owner-profile.md`：你的背景和偏好。
- `long_term/preferences.md`：长期记忆示例。
