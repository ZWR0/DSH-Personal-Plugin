# 灵犀御机

暗金插件包的 Windows 电脑操控插件。本地派生自 dsh-computer-use-win 0.5.3，保留 MIT 许可与第三方声明。

## 使用

通过 DSH 插件管理器安装此目录，替换原 dsh-computer-use-win，避免两个电脑提供者并行运行。设置入口：左侧「插件」→「灵犀御机」。修改后点击「保存更改」。保留原配置 entry id 和工具前缀 mcp__wincu__，已有桌面工具调用无需改名。

## 能力

Windows UI Automation 控件读取、截图、OCR、点击、输入、滚动、拖动和窗口管理；网页优先使用原有浏览器通道。完整、精简、按需和自定义工具加载可在设置中选择。

「突出显示鼠标」统一控制独立圆角深色箭头、细暗金描边与渐淡轮廓阴影（无外围圆形光圈、无文字标签），桌面指示层只跟随 Agent 的实际操作目标，用户移动系统鼠标不会改变标记位置；箭头偏移显示，目标框标示实际点击位置，并在点击时高亮；这是可视化标记，不是独立的第二套输入设备。指示层穿透点击，操作结束后自动隐藏。设置中的「目标移动动画」可在 0–1000 毫秒之间调整，0 表示立即到达；动画会增加对应操作的等待时间。Esc 停止当前桌面操作序列。网页操作使用独立页面指针，用户可以继续移动系统鼠标；页面指针进入全屏容器后仍然可见。浏览器任务同时显示原生暗金状态条，区分正在操作与等待下一步，不抢焦点、不显示系统鼠标替身、不拦截 Esc；用 DSH 停止按钮中断。状态条和页面标记分别遵循接管提示与突出显示鼠标开关。

界面跟随 Aurum 的亮暗主题令牌；Windows 提示层使用炭黑底、香槟金边缘、圆角深色鼠标、细暗金描边与渐淡金色轮廓阴影。保留远程与录屏可见开关。

## 设置页面

工具预设、选中项和预览图沿用 Aurum 金色主题令牌，兼容亮暗主题与窄屏。自定义清单支持按名称、用途或工具标识搜索；搜索只筛选显示内容，分组勾选仅作用于当前匹配项，全选与全部关闭仍作用于完整清单。切换预设保留自定义清单，修改后点击保存。

接管提示的「更多选项」支持修改提示文字、位置、保留时间与远程可见性。请先保存，再预览实际效果。

`open_browser` 提供明确的网页入口，接收 `url` 和 `activate`，独立模式返回后续操作使用的 `opened.id`。当用户指定复用已有浏览器时，`reuseExisting: true` 通过系统浏览器入口请求新标签页，沿用浏览器登录状态并返回原生窗口列表，后续使用 UIA 操作；不覆盖 DSH 页面。`activate: true` 展示网页，`false` 保持后台焦点。设置页的「复用已有浏览器」决定默认入口，可按任务通过 `reuseExisting` 覆盖。开启时窗口保持可见，独立浏览器的记住登录选项不适用。全能与精简方案包含此工具，自定义清单可单独控制。

网页观看和全屏播放任务要求 Agent 展示实际视频标签页，并读取 `media.fullscreen`、`videos[].paused`、`currentTime` 和 `readyState` 验证状态。点击成功不等于播放或全屏成功；验证码、登录限制与无法观测的状态须如实报告。

## Model Experience

启用的 MCP 工具会占用模型上下文。截图作为图像输入；不额外调用模型，不改变 KV 缓存策略。

## 已知限制

仅 Windows；需要 PowerShell、UIA 与交互式桌面。网页通道可并行使用独立页面指针与用户系统鼠标。原生桌面真实输入仍共享 Windows 鼠标和焦点；后台 UIA 操作不占用系统鼠标，但不会提供独立桌面会话。原有浏览器通道和停止保护保留；移除社区宣传横幅与原项目 Wiki 资源，运行所需模块不裁剪。

## 本机验收

2026-11-03 已在现有 DSH web 配置加载，实测左侧插件面板入口、开关关闭和重新启用后的保存与刷新持久性。Windows 后端 self-test 通过，UIA、截图与输入后端可用；原生指示层实际编译并通过显示、关闭、点击穿透检查（cursorError=0）。未将这些检查描述为完整模型端到端任务验收。

桌面接管提示条显示提示文字、当前操作与停止快捷键；未自定义时使用 Esc。修改自定义快捷键后，提示条同步更新。

2026-11-04 在实际 DSH Web 与本地均衡模型上验证：独立浏览器从 B 站首页点击实际视频链接，工具观测到 `fullscreen: true`、`paused: false`；开启复用已有浏览器后，系统入口在现有 Edge 窗口中新开标签页，保留 DSH，播放页的实际截图显示全屏视频。最后的电脑操作工具因无法可靠确认全屏后的当前网址而中止，未继续人工操控。最新原生状态文案编译通过，须在下一次插件重载后启用。

## 维护与验证

此个人插件目录是唯一源码目录，本地 Web 配置直接链接这里。同步 GitHub 时提交插件源码、说明与 `tools/aurum-desktop-*.mjs` 验收脚本；`node_modules/`、本机设置、日志与验收图片由个人仓库 `.gitignore` 排除。

从个人仓库根目录运行 `node tools/aurum-desktop-client-test.mjs`，验证工具搜索、筛选后分组勾选、保存与放弃修改，以及提示文字校验。`node tools/aurum-desktop-protocol-test.mjs` 验证实际 MCP 参数声明与禁用工具拒绝。Windows 交互式桌面上可运行 `node tools/aurum-desktop-pointer-smoke.mjs` 和 `node tools/aurum-desktop-shortcut-smoke.mjs` 检查原生指示层；图片写入 `tools/.test-tmp/aurum-desktop/`。`node tools/aurum-desktop-visibility-test.mjs` 检查全屏页面指针、状态开关、浏览器状态条不拦截 Esc，以及切换桌面接管与轮次结束清理。`node tools/aurum-desktop-pointer-target-test.mjs` 验证原生目标坐标、中间移动、点击反馈、闲置隐藏与点击穿透。桌面操作结果中的 `agentTarget` 提供实际指示坐标。这些隔离检查不代表完整模型端到端任务验收。
