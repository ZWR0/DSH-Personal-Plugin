# 灵犀御机

暗金插件包的 Windows 电脑操控插件。本地派生自 dsh-computer-use-win 0.5.3，保留 MIT 许可与第三方声明。

## 使用

通过 DSH 插件管理器安装此目录，替换原 dsh-computer-use-win，避免两个电脑提供者并行运行。设置入口：左侧「插件」→「灵犀御机」。修改后点击「保存更改」。保留原配置 entry id 和工具前缀 mcp__wincu__，已有桌面工具调用无需改名。

## 能力

Windows UI Automation 控件读取、截图、OCR、点击、输入、滚动、拖动和窗口管理；网页优先使用原有浏览器通道。完整、精简、按需和自定义工具加载可在设置中选择。

「突出显示鼠标」统一控制独立圆角深色箭头、细暗金描边与渐淡轮廓阴影（无外围圆形光圈、无文字标签），桌面指示层实时跟随系统指针；这是可视化标记，不是独立的第二套输入设备。指示层穿透点击，操作结束后自动隐藏。Esc 停止当前桌面操作序列。浏览器后台操作通过网页内指示标记显示。

界面跟随 Aurum 的亮暗主题令牌；Windows 提示层使用炭黑底、香槟金边缘、圆角深色鼠标、细暗金描边与渐淡金色轮廓阴影。保留远程与录屏可见开关。

## 设置页面

工具预设、选中项和预览图沿用 Aurum 金色主题令牌，兼容亮暗主题与窄屏。自定义清单支持按名称、用途或工具标识搜索；搜索只筛选显示内容，分组勾选仅作用于当前匹配项，全选与全部关闭仍作用于完整清单。切换预设保留自定义清单，修改后点击保存。

接管提示的「更多选项」支持修改提示文字、位置、保留时间与远程可见性。请先保存，再预览实际效果。

## Model Experience

启用的 MCP 工具会占用模型上下文。截图作为图像输入；不额外调用模型，不改变 KV 缓存策略。

## 已知限制

仅 Windows；需要 PowerShell、UIA 与交互式桌面。桌面箭头标记跟随真实系统鼠标，不能让用户和 Agent 同时独立操控桌面。原有浏览器通道和停止保护保留；移除社区宣传横幅与原项目 Wiki 资源，运行所需模块不裁剪。

## 本机验收（2026-11-03）

已在现有 DSH web 配置加载，实测左侧插件面板入口、开关关闭和重新启用后的保存与刷新持久性。Windows 后端 self-test 通过，UIA、截图与输入后端可用；原生指示层实际编译并通过显示、关闭、点击穿透检查（cursorError=0）。未将这些检查描述为完整模型端到端任务验收。

接管提示条仅显示当前配置的停止快捷键；未自定义时显示 Esc。修改自定义快捷键后，提示条同步更新。

## 维护与验证

此个人插件目录是唯一源码目录，本地 Web 配置直接链接这里。同步 GitHub 时提交插件源码、说明与 `tools/aurum-desktop-*.mjs` 验收脚本；`node_modules/`、本机设置、日志与验收图片由个人仓库 `.gitignore` 排除。

从个人仓库根目录运行 `node tools/aurum-desktop-client-test.mjs`，验证工具搜索、筛选后分组勾选、保存与放弃修改，以及提示文字校验。Windows 交互式桌面上可运行 `node tools/aurum-desktop-pointer-smoke.mjs` 和 `node tools/aurum-desktop-shortcut-smoke.mjs` 检查原生指示层；图片写入 `tools/.test-tmp/aurum-desktop/`。这些检查不代表完整模型端到端任务验收。
